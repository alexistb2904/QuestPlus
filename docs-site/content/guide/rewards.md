# Rewards and progression

Open a quest's **Rewards** tab. Add items, XP, advancements, messages, stages, random pools, player choices or reusable reward tables.

| Progression | Behavior |
| --- | --- |
| `once` | Finish once |
| `repeatable` | Restart when eligible |
| `infinite` | Start another cycle |
| `tiered` | Reach multiple milestones |

Optional cooldowns, time limits and automatic claiming change when rewards can be collected.

::: warning Security
Command rewards are disabled by default. Enable them only for trusted, reviewed packs.
:::

To provide a reward from your mod, use [the Java extension API](/reference/java-api).
