# Use the tablet

Press **J** to open the tablet. Change the key in Minecraft Controls.

Choose a **category** and select a **quest** to view its objectives, prerequisites and rewards.

| Action | How |
| --- | --- |
| Track a quest | Pin it to the HUD |
| Collect rewards | **Claim** or **Collect All** |
| Hand in items or XP | Use **Submit** |
| Trigger a manual quest | Its action button or `/questplus trigger <quest>` |
| Play together | Open the **Team** controls |
| Adjust visuals | Tablet settings for size, lighting and 2D mode |

You can pin up to three quests. Completed quests unpin automatically. The server validates progress even when the tablet is closed.
