# Quest Studio assets

- `questplus-logo.png`: QuestPlus logo supplied by the project owner.
- `studio-landscape.webp`: existing local Minecraft screenshot `2026-10-18_01.34.41_4K.png`, converted to a 1400px WebP on 2026-11-04. Used for the masthead scenery, no generated image.
- `textures/stone.png`, `dark-oak.png`, `grass.png`: Minecraft Java 26.3 textures, Mojang/Microsoft, sourced from the same Minecraft asset archive already used by the editor: https://assets.mcasset.cloud/26.3/assets/minecraft/textures/block/stone.png, https://assets.mcasset.cloud/26.3/assets/minecraft/textures/block/dark_oak_planks.png, https://assets.mcasset.cloud/26.3/assets/minecraft/textures/block/grass_block_side.png.
- `fonts/pixelify-bold.ttf`: Pixelify Sans, Google Fonts distribution. SIL Open Font License in `fonts/OFL.txt`, source https://github.com/google/fonts/tree/main/ofl/pixelifysans.
- Interface icons: Lucide React, ISC license, https://lucide.dev/guide/react/. Only imported icons enter the bundle.

Minecraft imagery remains the property of its respective owners. This editor is an independent QuestPlus tool.
